# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии по [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-06

Первый публичный релиз. Подпись версии — зелёный прогон тестов:
**56 passed**, сборка колеса `verity-0.1.0-py3-none-any.whl` успешна.

### Добавлено

- `verity_gate.py` — гейт: живые HTTP-пробы всех маршрутов, вердикт по
  каждому, `register.json` на выходе. `--list-only` работает без сети.
- `register.json` — реестр проверок: **77 маршрутов**, технический и ручной
  вердикт каждого.
- `docs/CHANNELS.md` — канал первого дня: 8-колоночная таблица
  подтверждённых маршрутов, счёт и статус долга D-1.
- `tests/test_verity_gate.py` — тесты логики вердиктов, сеть не используется.
- `SECURITY.md`, `CONTRIBUTING.md`.
- `pyproject.toml` — до этого файла не было, продукт не устанавливался.

### Исправлено

- **Парковщик с JS-заглушкой `/lander`** пойман: площадка отдавала заглушку
  вместо ответа. Реестр обновлён, вердикт пересчитан.
- **Дрейф вердиктов = 0** после третьего прогона: два независимых запуска
  дали идентичный реестр — значит гейт детерминирован.
- Движок гейта возвращён под контроль версий (раньше жил вне репозитория).
- Сборка тестов починена, добавлена живая проверка условий по 5 кандидатам.

### Проверено вживую

- Проверено **из чистого клона GitHub**: 56 тестов, `--list-only` отдаёт
  77 строк, вердикты идентичны.
- Условия и комиссии по 5 кандидатам проверены живым запросом 06.10.2026.

### Ограничения (честно)

- **Счёт подтверждённых каналов сбыта: 0 из 3.** Техническая ось жива
  (77/77 маршрутов отвечают по HTTP), но третья ось — ручная подпись
  владельца `owner_verified` — автономно не выдаётся. Пока не выдана,
  `channels_counted` закономерно остаётся 0.
- Каналы с KYC и логином гейт не проверяет — только публичные HTTP-маршруты.
- Приватные каналы (TG/VK) в реестр не входят.
